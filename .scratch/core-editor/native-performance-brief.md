# Native performance acceptance

## Original user brief

Build an ultra performant, efficient, production-ready native Rust desktop AI
video editor comparable to CapCut/Palmier Pro on macOS, Windows and Linux. Use
Neptune at `/home/biggabo/Documents/Projects/rust-terminal/rust-terminal` as a
read-only engineering/stack/reference-docs source. The interface should be
original, modern, sophisticated, friendly and minimal, with rounded icons and
quiet text.

Core requirements: project create/open/save/autosave/duplicate/settings/undo/redo;
video/image/GIF/audio/file/folder/drop import; library thumbnails/folders/search/
sorting/source previews; unlimited model video/audio/text tracks with snapping,
zoom and markers; trim/split/crop/move/copy/paste/duplicate/delete; ripple/link/
group/lock/hide/mute; real preview/scrub/frame-step/speed; position/scale/rotation/
opacity/reflections; canvas presets/custom resolution/background; full history,
checkpoints and recovery. Native AI edits share the validated command boundary.
Do not call the original production/parity goal complete from this acceptance.

## Prior findings, responses and remaining objections

Core UI rounds 1–5 implemented/refined the native egui/wgpu interface and passed
13-check X11 smoke plus scoped Wayland/drop/GIF/history evidence. The original
core checkpoint had 169 tests; its paused CPU/RSS samples predate native AI.
Native AI rounds 1–3 wired real CLI planning and protected document sessions.
Codex initially failed three requests on a oneOf schema; backend switched to
supported anyOf/enum tags, explicit executable resolution and private nonempty
planner instructions. Models sometimes described a split while returning an
unchanged transform; typed validity alone does not establish intent.

Source round 4 added create-only Save As for unbound restored work. Native
round 5 (db30/9f72, `artifacts/native/ai-round8/report.json`) passed real GTK
legacy/private recovery refusal/adoption, provider exact split/undo/redo and
scoped Claude cancellation/Codex bad-plan/reopen behavior. Source round 6 added
truthful net-no-op feedback/history preservation, bringing tests to309.
Native round 7 (`artifacts/native/ai-round9/report.json`, source2825/binary2c59)
passed all four required gates plus GTK import: owned no-op/stale fixtures,
both real default CLIs correct on their first request, exact undo/redo,
normal/narrow captures and13/13smoke. No product failures. Root accepted quiet
card-only Apply feedback; no separate toast is needed. Earlier failures remain
preserved; no native macOS/Windows or physical A/V acceptance was established.

Backend checkpoint round8 (313 tests, source3a4c/binary89af) added portable
provider fault tests and a zero-gain audio decoder fix. Linux tests and full
Mac ARM64/Windows MSVC/Windows GNU source/lint checks passed; cross-target checks
did not link or run. Subsequent audio regressions reproduced stale/future PCM,
obsolete-clock activation and a startup playhead rewind. The scheduled
generation/frame buffer and monotonic handoff correction passed focused tests;
Mixer retained-voice/sequential-cut budget corrections followed. Use only the
new frozen checkpoint granted in the delegation, never an older binary.

Unresolved production gates: actual target hosts/SDK/link/runtime/signing,
complete platform input/IME/accessibility/DPI/portal behavior, actual DAC/display
A/V timing and underruns, VFR/HDR/hardware/proxy/color work, long sessions and
slow storage/clean-machine deployment. Metadata AI is not audiovisual analysis.
Current preview policy bounds simultaneous audible voices; model tracks have
no fixed count. Do not equate software capture throughput with presentation fps.

## Grant and bounded scope

The delegation supplies the exact immutable source/build checkpoint and binary
hashes. No Cargo, source/manifests/script changes or rebuilding. Write only fresh
task-owned test artifacts and necessary coordination outcome. Stop and report
a product defect for a separate source round. Do not repeat real-provider calls
unless a relevant native integration regression makes one necessary; current
production provider code is unchanged from accepted source.

Own displays/compositor/settings/projects/media/portal/processes. Never drive
or capture unrelated desktop windows or change system audio routes/volume/power
settings. No microphone/monitor capture or nonzero physical test tones. No
compilation or CPU-heavy unrelated task will run during timed intervals.
Root separately measures public AudioService silence on its inherited physical
default output; a private UI display with no sound server is not audio proof.

1. Verify supplied source/binaries and fresh media hashes before/after. Run
   existing13-check native smoke against the exact executable. Capture normal
   1440×900 and narrow760×560 current editing states; retain full-project exact
   reversal for one held gesture and a source preview that does not mutate.
2. Repeated paused empty/loaded observations: at least3 trials each,6s warmup,
   about15s sample. Sample process CPU/RSS from OS counters without frequent
   agent inspections waking the editor. Include retained decoder children,
   stable PID/start identities and actual sample lengths. Report one-core CPU,
   summed process RSS limitations, source/cache conditions and workload.
3. Try actual minimized behavior only with an owned window manager/compositor.
   If unavailable, say so; an unmapped window is not a minimize acceptance.
   Identify actual adapter/renderer/driver. An owned accelerated path may be
   attempted without global desktop changes; preserve failures and scope any
   software fallback. Never infer hardware acceleration from an installed GPU.
4. Native5,000-clip/20-track timeline: synthetic valid project, real scroll/zoom/
   selection/held drag/undo. Observe response latency with a stated capture or
   event method and repeated samples where defensible. Pure reducer times are
   separate. No test-only commands bypass the input path being measured.
5. Real synthetic interframe-video random scrubs/source playback: at least20
   seeks across the clip, separating first decoder/cold requests from retained
   warm requests. Visible time/frame labels must match the latest seek rather
   than a late older completion. Include a sustained30s source-rate preview
   observation, observer overhead and missed/stale samples. Captured frame
   updates are not native compositor/vblank/DAC timestamps; do not invent
   dropped-frame or frame-time distributions without a valid observation.

Keep the work bounded to these cases. Retain initial failures/abandoned runs,
counts/causes/retries, raw samples, captures, method, host/tool versions and
all limitations in `artifacts/native/performance-round1/report.json`. Hash
source/binaries/media after completion and clean up exactly the owned children,
displays and portals, proving their termination. No watchers or pending work
remain when you return. Request missing constraints through root if necessary;
routine reversible choices are authorized by this brief.
