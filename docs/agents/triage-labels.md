# Triage Labels

Canonical roles map directly to these tracker status strings:

- `needs-triage`: maintainer needs to evaluate the issue.
- `needs-info`: waiting on the reporter for more information.
- `ready-for-agent`: fully specified, ready for autonomous implementation.
- `ready-for-human`: requires human implementation.
- `wontfix`: will not be actioned.

When a skill mentions a triage role, use its matching string in the
issue's `Status:` line.
